# 自媒体选题与任务联动

- 新建任务选择自媒体后，可选择未发布且没有关联任务的选题，包括未开始和工作中。选择后带入预计发布日；已有任务的选题不会重复出现在候选项。
- 选题的系列既可选择已有值，也可在输入框填写新值；保存后新系列进入候选列表。
- 新建或编辑尚未关联任务的选题时，可选择未完成、未关联其他选题的自媒体任务。关联时以选题当前状态和日期为准，覆盖目标任务的相应字段。工作中且未选择已有任务时，沿用自动创建任务的行为。
- 选题与任务为一对一关系；提交时再次检查，不允许抢占已有关系。已有关系不通过空选择解除。已关联任务不允许改成非自媒体分类。

| 选题 | 任务 |
| --- | --- |
| 预计发布时间 | 截止日期 |
| 实际发布时间 | 实际完成日期 |
| 工作中 | 正在做 |
| 未开始 | 待安排 / 下一步 |
| 已发布 | 已完成 |

选题使用精确 UTC 时间；任务使用当地全天日期。任务侧改日期时保留选题原来的当地时分；没有原时间时使用当地零点，新完成任务优先使用完成操作时分。若保留的时分会产生未来的实际发布时间，则使用该日零点。单纯修改标题或排序不改写发布时间。

填写实际发布时间会将选题设为已发布；已发布但没有填写时间时使用当前时间。重新打开任务或将选题改回未发布状态，会清除实际发布时间及任务完成信息。删除一侧不会删除另一侧。

## 验收

1. 新建自媒体任务选择未发布选题，确认日期带入、已占用项排除，以及加载失败后可以重试。
2. 编辑未关联任务的选题，选择已有任务并保存，确认没有创建重复任务；取消编辑不保存选择。
3. 从两端分别修改预计日期、完成日期和状态，检查 Calendar、看板与选题库显示一致。
4. 使用 Asia/Shanghai 跨 UTC 日期的实际发布时间，确认任务显示当地日期且不会把完成操作时间当成发布时间。
5. 新建系列后再次编辑其他选题，确认可从下拉列表选到；系列首尾空白被移除。
