# 选题发布日历与清单分页

- 日历位于共享筛选栏下、清单上；默认展开，可折叠，浏览器记住选择。
- 每条选题优先取 `published_at`，为空时取 `scheduled_at`，按浏览器本地时区归入日期；均为空的进入未排期。
- 已发布用绿色，未发布用蓝色。一个选题只显示在一个日期，具体时间标注实际或预计。
- 桌面每格最多显示 3 条，更多按钮筛选当天清单；手机以数量呈现，选择日期后在下方查看内容。
- 顶部搜索、状态、表现、系列同时影响日历和清单。日期选择仅进一步筛选清单，不缩减日历。
- 清单采用前端分页，每页可选 10/20/30 条，默认 20，设置保存在浏览器；过滤、排序、修改页大小后回到第一页。日历使用完整筛选结果，不使用当前页切片。
- 本功能不新增 API 或数据库字段。之前“分析与复盘”的 migration 仍需按原流程执行。

## 手动验收场景

1. 准备有实际时间、只有预计时间、没有任何时间的选题，确认分别按正确日期归类或显示在未排期清单。
2. 同日安排 5 条，桌面日历显示 3 条和“还有 2 条”；点击后清单包含当天全部选题。
3. 同一筛选条件超过 30 条，分别选择 10/20/30 条翻页，确保无遗漏和重复，刷新后保留页大小。
4. 在最后一页修改筛选、排序或页大小，确认回到第一页；点清除日期恢复全部日期。
5. 切月、回到今天、收起/展开、切换深浅主题；手机布局中日期、数量和清单可操作。
6. 跨 UTC 日期的发布时间按浏览器当地日期显示；有实际时间时不再重复显示在预计日期。
7. 网络失败时显示错误与重试，日历不展示过期结果；浏览器存储不可用时仍可使用折叠和分页设置。

未自动启动服务器或运行自动化测试。
